# 澳門英文學堂 · 小五小六

獨立本機試玩版；沿用小一至小四奶油底色、薄荷綠、淡紫、圓角字體及「抽背 → 生字卡 → 文法」學習次序。已加入原創「星光隧道」跑跳遊戲，本版只保留這一隻遊戲。儲存鍵 macau-upper-primary-v1，不會改動之前兩個 App 的記錄。

## 內容

Primary Longman Elect 第二版 5A、5B、6A、6B，共24課、358張核心生字／詞組卡。每課15條文法情境變體，來自每課5個原創題型、各3個人名版本；目前合共120個題型、360條變體，後續可擴充不同情境及題式。這是首版核心溫習內容，不是完整課文或學校評核清單。

課名及文法重點已核對出版社目錄及公開教學重點。中文解釋與練習原創。

- https://elect2e-promo.pearson.com.hk/book/
- https://elect2e-promo.pearson.com.hk/wp-content/uploads/2022/11/01_plet2e_otf_vocab.pdf
- https://elect2e-promo.pearson.com.hk/wp-content/uploads/2022/11/02_plet2e_otf_lf.pdf

## 功能

- 按年級、分冊及單元選擇；按年級記錄文法完成情況。
- 抽背前勾選生字、設定數量、隨機抽背；每個詞7個字母或以下留2格，8個或以上留3格。
- 點字母或鍵盤填字；錯字標紅、顯示正確拼法、重試改空格。
- 生字卡發音、揭中文、上一張／下一張；聆聽與中文對應選擇題。
- 文法選項隨機排列、中文解釋、答錯原題重試、首答分數。
- 內置美式音檔及慢速播放，使用與三四年級相同的 Kokoro af_heart 聲線、en-us、speed .9。課內詞彙不使用系統 speechSynthesis。
- 本機 localStorage，未提供登入或雲端同步。

## 執行與驗證

在此資料夾執行 `python3 -m http.server 8090 --bind 127.0.0.1`，開啟 http://127.0.0.1:8090/ 。
使用 Node 執行 `node verify.mjs` 核對24課順序、詞彙、答案唯一性、抽背空格與重試空格。語法檢查通過；已實測手機窄版排版、選年級／分冊、文法答錯重試、生字勾選、點字母答題及六下生字卡。音檔對齊三四年級的生成設定；相同文字沿用相同檔案，新增文字使用同模型及聲線生成。


## 星光隧道（2026-11-10）

第一個原創遊戲，參考隧道跑跳這類玩法；自製 Canvas 透視隧道、八面旋轉、固定種子路線、缺口、星星及漸進速度。角色及聲效沿用本專案素材，沒有載入第三方遊戲或使用其關卡、程式及角色。參考頁：https://poki.com/zh/g/run-3 。

手機按鈕／方向鍵左右換面，空白鍵或上方向鍵起跳，長按延長跳躍；支援暫停、分頁離開自動暫停、最佳距離本機儲存及返回學堂。每130米進一關並加速，起步11.8、最高19單位／秒。目前為自由試玩，未接入學習機會／復活獎勵。

驗證：`node games/starlight/engine.test.mjs` 通過；已於手機窄版實測完整App入口、開局、按鈕轉面／跳躍、暫停、跌落結果及重玩。安全路徑、落地、穿越缺口及暫停距離亦有引擎測試。

2026-11-10 調整：原創背面角色、修正投影左右方向、電話按鈕加大及長按轉面、鍵盤與觸控共用0.19秒長按節奏；缺口由25%隨路程增加至42%，保留首10列安全區。

轉面容錯：從實地轉面有320毫秒緩衝；缺口邊緣另有160毫秒補跳窗口。於缺口上連續轉面不會重新取得緩衝。已測試過早轉面、補跳及避免重複刷新。

角色v4：原創透明三格3D背向跑步素材（imagegen），取代平面繪圖。遊戲內置動感runner-sprint配樂，開局／繼續播放，暫停／失敗／離開停止；獨立音樂開關，開遊戲時暫停學堂背景音樂。
